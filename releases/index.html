More clarity at every step.

Latest release

Release 6.9

November 5, 2026

This update makes project submissions and reviews easier to navigate, adds more flexibility to digital forms, and gives administrators clearer tools for managing requests and project information.

Simpler submissions More guided data entry and clearer monitoring reports.
More flexible forms Improved request management, notifications, and exports.
Smoother reviews Consistent updates, clearer prompts, and automatic saving.

Project Submission Tool

  • Calculation fields now appear or hide based on your selections, helping you focus on the information needed at each step.
  • Monitoring reports now include the monitoring period when custom methodology templates are used.

Digital Forms

  • Administrators can filter the NOVS list by project proponent.
  • When a Registry user denies a request, they must select a reason. The reason can then be included in the decision letter.
  • Exemption requests that were pre-approved or returned can now be updated.
  • NOVS export files now use an updated date format.
  • The submit button is now available on communications agreements with multiple project proponents.
  • Additional VVB contacts listed on exemption request forms are now copied on request email notifications.
  • Administrators can download a PDF report of all comments on an exemption request.

Review Tool

  • A project remains marked as “Assigned” after it is reassigned to a new category.
  • Required-field messages remain visible until all required fields are complete.
  • A confirmation message appears when you change a finding’s issue type.
  • Issue types added in one document are now available in the other documents in the same review.
  • Changes to documents, findings, and comments are now saved automatically.
  • Deadline warning emails now show the updated dates after an exemption request is approved.
  • Verra’s response now displays correctly in reviews.
  • Review rounds now update correctly.

General Improvements

  • Interface updates make Project Hub easier to use.
  • Billing information from the registry billing system can now sync to Project Hub.
  • Registry information is now available on Verra’s public website.
  • Data is now extracted automatically during registry synchronization.
  • Data exports now include a filter.
