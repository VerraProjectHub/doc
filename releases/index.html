Project Hub Release Notes

We’re excited to share the following Project Hub updates

V 6.10 November 6, 2026

Project Tracker

  • There is now a maximum of three prioritization requests per portfolio, except for the unlimited E&I portfolio, so that requests for individual or joint projects are accepted only when all applicable portfolios have available capacity.
  • Stakeholders will now receive more detail on what items are needed for a prioritization request to be made

Miscellaneous

  • Updated registry sync from project hub to retain any saved documents for if there is a sync issue

Documentation

  • Release notes are now available through the documentation portal, and DSP directory links have been updated to direct users to the new documentation site.

V 6.9 November 5, 2026

Project Submission Tool

  • Updated calculation input conditional rules
  • Fixed an issue where the monitoring period was not printed on the monitoring report PDF for custom methodology templates

Digital Forms

  • Admins can now filter NOVS list by project proponent
  • Registry users now must select a reason when “Deny” is chosen so that a more decision letter can be generated for the user
  • Users now have the option to update pre-approved or returned exemption requests
  • Updated date format in the NOVS export file
  • Fixed an issue where the submit button was not available for some multi project proponent communications agreements
  • If additional VVB contact is specified on exemption request form, the VVB will be copied on email notifications sent for the request
  • Admins can download a PDF report that contains all comments left for an exemption request

Review Tool

  • After a project is re-assigned with a new category the status stays “Assigned”
  • “This field is Required” messages now stay on screen for reviewers until all required fields are entered
  • The change finding typology confirmation dialogue box is now shown when an issue type is changed
  • When an issue type is added in one document it now gets displayed in other documents within the same review
  • When editing documents, findings, and making comments changes are automatically saved
  • Update delivery of deadline warning emails to account for new dates after exemption requests are approved
  • Fixed an issue where Verra response was not properly showing in some PRR’s
  • Fixed an issue that caused PRR rounds to update incorrectly

Miscellaneous

  • UI updates to enhance the overall look, feel, and functionality of the Project Hub
  • Implemented Zoho/Raas billing API with our registry sync service so that billing information can be synced into Project Hub
  • Registry information can be seen on Verra public site
  • Automated data extraction during registry sync process
  • Added filter to data export
